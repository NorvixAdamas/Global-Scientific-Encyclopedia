    🌐 Liên kết tải dữ liệu gốc — nguồn mở quốc tế

    Các nguồn dữ liệu chuẩn dùng để scale lên hàng triệu bản ghi. Tất cả đều miễn phí, không cần API key cho tra cứu cơ bản.

    🛠️ Công cụ & thư viện Python

    pip install chembl_webresource_client — Truy vấn ChEMBL API từ Python
    pip install pubchempy — Tra cứu PubChem compound/property
    pip install ord-schema — Parse & validate phản ứng ORD Protocol Buffers
    pip install mp-api — Materials Project API (cần đăng ký key miễn phí)

    💡 API tra cứu nhanh (dán URL vào trình duyệt)

    🔍 Tra CID của aspirin: ...pubchem.../name/aspirin/cids/JSON
    📊 Lấy SMILES + khối lượng: ...pubchem.../cid/2244/property/.../JSON
    🧬 Tìm molecule ChEMBL: ...ebi.ac.uk/chembl/api/data/molecule?limit=5
    💊 Tra cứu thuốc theo tên (ChEMBL): ...chembl/.../molecule/search?q=aspirin
